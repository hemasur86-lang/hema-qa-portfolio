## 🎯 Project Overview

The E‑commerce application was tested thoroughly across all major modules:

- Login & Authentication  
- Product Search  
- Product Details  
- Add to Cart / Remove from Cart  
- Checkout & Payment  
- Order History  
- Profile Management

## 📝 Test Artifacts Included

### ✔️ Functional Test Cases (TC01–TC09)
Each test case includes:
- Test objective  
- Preconditions  
- Detailed steps  
- Expected results  
- Actual results  
- Status  

### ✔️ Regression Suite (RT01–RT03)
Ensures previously working features remain stable after fixes or new changes.

### ✔️ RTM (Requirement Traceability Matrix)
Maps:
- Requirements → Test Cases → Regression Tests  
Ensures complete coverage.

### ✔️ Bug Reports (BUG01–BUG03)
Each bug report includes:
- Steps to reproduce  
- Expected vs actual result  
- Severity & priority  
- Screenshots  
- Environment details  

### ✔️ Test Summary Report
Final cycle summary including:
- Test coverage  
- Defect summary  
- Pass/Fail statistics  
- Risks  
- Release readiness

# 🔌 API Testing

This folder contains API test cases, Postman collections, and bug reports for the E‑commerce application.

## 📁 Files Included
- API_TestCases.xlsx  
- Postman_Collections.json  
- API_Bugs.pdf  
- README.md  

## 🎯 Scope of API Testing
- Authentication (Login API)  
- Product listing  
- Product details  
- Cart operations  
- Checkout  
- Order history  

## 🔧 Tools Used
- Postman  
- JSON Validator  
- GitHub  
- Chrome DevTools (Network tab)

## 🚀 How to Use
1. Import Postman_Collections.json into Postman  
2. Run each API request  
3. Compare response with API_TestCases.xlsx  
4. Log defects in API_Bugs.pdf
